Hardware entropy,
on this machine.

This host is a Lokey True Randomness as a Service node. An ATECC608 secure element captures physical noise. The API keeps that entropy in memory, Fortuna mixes it, and VirtIO hands it to virtual machines. Traefik is the front door on port 443. Nothing here is written to disk, and this page does not set cookies.
